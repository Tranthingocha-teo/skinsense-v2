A skin diary that measures redness on the device.

SkinSense lets people photograph their skin every night under a guide, mark spots by hand and follow per-zone redness over time, on the web and on Android.

01 · Problem

Skin changes slowly, and memory is a bad instrument.

Photos taken at a different distance, angle or light cannot be compared night to night. An earlier version of this project showed acne counts that turned out to be hardcoded sample data.

The rebuild set two rules: every number comes from a measurement the user can inspect, and the app never diagnoses.

02 · The product

Four steps, every night.

03 · Measuring redness

Relative to your own skin, in the same photo.

1Face landmarks468 points, the same mesh on web and Android.
2Skin maskSkin separated from hair, eyes and background.
3Five zonesForehead, both cheeks, nose and chin, built from landmarks.
4a* indexMedian a* of the zone minus median a* of all skin (CIELAB).

Why relative

Comparing each zone with the rest of the same face cancels most of the camera and room, so there is no global white-balance step. White balance is locked at capture instead.

Where it fails

A whole face that is inflamed, mixed lighting, darker skin compressing a*, and shadows on the nose and chin. The app says so instead of hiding it.

04 · Design

Three directions, one night photo.

A font that broke Vietnamese

Cormorant Garamond placed the circumflex on ô visibly off the letter at every weight, in Chrome and on Android. The display face became Noto Serif Display 300.

One token file

tokens.json feeds CSS variables on the web and NativeWind on Android. The build fails if any of 24 text pairs drops below WCAG AA in either theme.

05 · Engineering

Decisions that held up under measurement.

468 landmarks on both platformsWeb and Android share the mesh size, so zones are computed once in a pure TypeScript domain package.
Google sign-in without redirectsBoth apps hand Supabase a Google ID token; a redirect flow does not return cleanly into an installed app.
Sticky, not pinnedA GSAP pin re-parented the hero and re-emitted the headline as a late LCP. CSS sticky with a scrubbed timeline avoids it.
Motion layout from the first paintSwitching layout classes after hydration measured CLS 0.74. A scripting and reduced-motion media query brought it to 0.
